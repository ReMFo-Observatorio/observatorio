# Observatorio ReMFo

Observatorio público de la **Alianza Latinoamericana de Resistencia al Monocultivo Forestal** (ReMFo).

Una plantación no es un bosque. Un pastizal, un humedal, una sabana o un matorral tampoco son un bosque degradado al que haya que llenar de especies exóticas.
